Compte et connexion¶

  1. Ouvrir le tableau de bord en ligne, https://projecta-dash.vercel.app, ou l’application de bureau, puis Continuer.
  2. La première fois, S’enregistrer : nom, prénom, adresse e-mail et mot de passe (8 caractères au moins).
  3. Se connecter avec l’adresse et le mot de passe. Sans Se souvenir de moi, la session dure 30 minutes (JWT_EXPIRE_MINUTES).

  1. L’adresse e-mail du compte.
  2. Le mot de passe (l’œil l’affiche).
  3. Se souvenir de moi : la session reste ouverte 7 jours.
  4. Mot de passe oublié ? : un code par e-mail pour en choisir un autre.
  5. Google ou GitHub, s’ils sont configurés sur le serveur.
  6. S’enregistrer : créer un compte.

Se souvenir de moi garde la session 7 jours et l’adresse e-mail : la fois suivante, la page de connexion la remplit (case cochée), et, si la session est encore ouverte, propose Ouvrir le tableau de bord ou Changer de compte. Le mot de passe n’est jamais gardé par l’application ; le gestionnaire de mots de passe du navigateur peut le proposer.

Quand la session expire, la page de connexion le signale : il suffit de se reconnecter.

Avec Google ou GitHub¶

Si l’administrateur l’a configuré, deux boutons ronds apparaissent sous Se connecter et S’enregistrer : Google et GitHub.

  1. Cliquer sur l’un d’eux : la page de Google ou de GitHub s’ouvre (dans l’application de bureau, dans votre navigateur, qui demande ensuite d’« ouvrir Projecta »).

  2. Se connecter chez eux et accepter : le tableau de bord s’ouvre.

  3. Première fois avec cette adresse : un compte est créé, avec le nom donné par Google ou GitHub, sans mot de passe (on peut en définir un dans Profil).

  4. Un compte existe déjà avec cette adresse : la connexion s’y fait, et Google ou GitHub lui est relié.

Projecta ne reçoit jamais votre mot de passe Google ou GitHub : seulement votre nom et votre adresse e-mail, si elle est vérifiée chez eux. Se souvenir de moi compte aussi pour cette connexion.

Mot de passe oublié¶

  1. Sur la page de connexion, Mot de passe oublié ?, puis l’adresse du compte et Envoyer le code.
  2. Un code à 6 chiffres arrive par e-mail ; il est valable 15 minutes.
  3. Taper le code et le nouveau mot de passe (deux fois, 8 caractères au moins), puis Changer le mot de passe : la page de connexion s’ouvre, l’adresse remplie.

Un nouveau code peut être demandé après une minute (Renvoyer le code) ; il remplace le précédent. Après 5 codes faux, il faut en redemander un. La réponse est la même pour une adresse sans compte.

Pas d’e-mail ?

Regardez les courriers indésirables. Sur un serveur d’essai, les e-mails peuvent être retenus par le serveur au lieu d’être envoyés : demandez à l’administrateur.

Compte¶

Le rond aux initiales, en haut à droite, ouvre le menu du compte.

Entrée Contenu
Profil prénom et nom (modifiables), adresse e-mail, date de création ; changement du mot de passe (le mot de passe actuel est demandé) ; Supprimer mon compte, après confirmation, avec ses espaces et leur historique
Langue Français ou English : le tableau de bord, l’application de bureau et ce guide ; gardée pour votre compte
Paramètres lignes par page, menu latéral réduit, panneau « Colonnes » ouvert à l’ouverture d’un jeu, visualisations affichées ; appliqués tout de suite et gardés dans ce navigateur ; Rétablir les réglages revient aux valeurs par défaut
Notifications les messages de la session (imports, erreurs, enregistrements), du plus récent au plus ancien ; le nombre de non lus s’affiche à côté de l’entrée
Se déconnecter ferme la session ; le jeton est révoqué

Langue¶

Compte › Langue : Français ou English. Le tableau de bord s’affiche tout de suite dans cette langue, l’application de bureau (ses menus et ses fenêtres) la suit, et le bouton du livre ouvre ce guide dans cette langue. Le choix est gardé pour votre compte : il vous suit sur un autre ordinateur. Les données (noms de fichiers, colonnes, descriptions des examens, valeurs des balises DICOM) ne sont jamais traduites.

Comptes reliés¶

  1. Identité : prénom et nom ; l’adresse ne change pas ici.
  2. Mot de passe : le changer, ou définir le premier.
  3. Comptes reliés : Google et GitHub.
  4. Supprimer mon compte (après confirmation).

Profil › Comptes reliés montre Google et GitHub : relié (avec l’adresse et la date) ou non.

  • Relier : la page du fournisseur s’ouvre ; au retour, une notification confirme. L’adresse doit être la vôtre, ou une adresse qui n’a pas encore de compte Projecta.
  • Délier : après confirmation. Impossible si c’est le seul moyen de vous connecter : définissez d’abord un mot de passe (Profil › Définir un mot de passe, sans mot de passe actuel à donner).
