Aide¶

Message Que faire
« Fichier hors du dossier autorisé » importer le fichier depuis l’ordinateur
« Table plus disponible » Se connecter dans le message rouvre l’onglet Base de données avec sa connexion
« Pas assez de colonnes numériques » choisir un autre jeu, ou plus de colonnes
« Connexion impossible » vérifier le serveur, le port, la base, l’utilisateur et le mot de passe
« La table existe déjà » (export) choisir « Remplacer la table » ou « Ajouter les lignes à la fin », ou un autre nom
La page de connexion s’affiche la session a expiré : se reconnecter
L’assistant dit qu’aucun modèle n’est configuré l’administrateur du serveur doit l’activer (clé de l’API)
« Adresse refusée » (serveur distant, PACS) le serveur est sur un réseau privé : l’administrateur peut l’autoriser
Aucun e-mail de code (mot de passe oublié) regarder les indésirables ; sinon, l’administrateur vérifie l’envoi des e-mails

L’assistant du guide¶

Le bouton rond en bas à droite de chaque page de ce guide ouvre son assistant : posez une question avec vos mots.

  1. Le bouton : ouvrir ou fermer l’assistant.
  2. La réponse, tirée de ce guide.
  3. Les pages où le guide en parle : un clic y va.
  4. Votre question (ou une des suggestions au-dessus).

L’assistant ne connaît que ce guide : il ne voit ni vos données ni votre compte. Selon votre serveur, il montre le passage du guide qui répond, ou rédige une réponse à partir de ces passages ; vérifiez les points importants sur la page indiquée. La conversation suit d’une page à l’autre, jusqu’à la fermeture de l’onglet.

Un autre problème¶

Écrivez à l’administrateur de votre serveur Projecta en donnant l’heure, l’écran et le message affiché. S’il vous demande un identifiant de requête, il figure dans les outils du navigateur (en-tête X-Request-ID).
